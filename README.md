# رازینو — Razino

بازی ماجراجویی معمایی دوبعدی فارسی برای کودکان ۸ تا ۱۲ سال.
A Persian, right-to-left 2D mystery-adventure for ages 8–12, built with
**Godot 4.3** and **GDScript**, targeting Android.

سند طراحی: [`docs/GDD.md`](docs/GDD.md) · معماری: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) · دارایی‌ها: [`docs/ASSETS.md`](docs/ASSETS.md)

---

## وضعیت فعلی — what actually works today

| | |
|---|---|
| موتور | Godot 4.3 (`4.3.stable.official`) |
| فصل‌ها | هر ده فصل به‌صورت دادهٔ اعتبارسنجی‌شده — ۱۶۶ صحنه، ۴۰ قسمت، ۲۲۳ خط دیالوگ، ۵۴ انتخاب، ۲۹ معما، ۹۶ سرنخ، ۲۱ پایان |
| صفحه‌ها | هر ۱۶ صفحهٔ سند طراحی، راست‌چین، با فونت وزیرمتن |
| تست | ۷۸ تست / ۸۴۷ assertion + ۱۹ بررسی یکپارچگی دانلود — همه سبز |
| خروجی اندروید | **ساخته نشده** — Android SDK در این محیط در دسترس نیست |
| گرافیک نهایی | **موجود نیست** — پس‌زمینه‌ها جایگزین موقت و علامت‌گذاری‌شده‌اند |
| صداگذاری | **موجود نیست** — ۲۵۰ خط هنوز ضبط نشده |

`docs/ASSETS.md` از روی دادهٔ خود فصل‌ها تولید می‌شود، بنابراین نمی‌تواند چیزی را بیشتر از آنچه هست نشان دهد.

## اجرا

```bash
godot --path .                       # اجرای بازی
godot --headless --import            # ایمپورت دارایی‌ها
godot --headless res://tests/test_runner.tscn   # تست‌ها؛ خروجی غیرصفر یعنی شکست
python3 content_tools/validate_content.py       # اعتبارسنجی محتوای هر ده فصل
python3 content_tools/build_all.py              # بازتولید فصل‌های ۲ تا ۱۰ و کاتالوگ
python3 content_tools/asset_report.py           # بازتولید docs/ASSETS.md
```

### دیدن صفحه‌ها بدون دستگاه

```bash
xvfb-run -a godot --path . --resolution 1280x720 res://tools/screenshot.tscn
```

### آزمون کامل دانلود محتوا

```bash
tools/run_integration.sh /secure/path/razino-content.key
```

بسته‌ها را می‌سازد و امضا می‌کند، یک نسخهٔ دست‌کاری‌شده هم کنارش می‌گذارد، روی
loopback سرو می‌کند و کل زنجیرهٔ دریافت → بررسی hash → بررسی امضا → فعال‌سازی
اتمیک → اجرای آفلاین را می‌آزماید.

## اصل طراحی

**فصل‌ها داده‌اند، نه کد.** موتور فقط واژگان بسته‌ای از شرط‌ها و اثرها را
می‌فهمد و چیز دیگری را اجرا نمی‌کند. به همین دلیل یک بستهٔ دانلودشده هرگز
نمی‌تواند کد اجرا کند، و نویسنده می‌تواند فصل یازدهم را بدون انتشار نسخهٔ تازه
در فروشگاه اضافه کند.

## کلیدها و تنظیمات

هرگز.
